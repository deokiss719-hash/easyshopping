# 이지핫딜 서비스 연결 (2026-09-30)

## 발견된 문제
- 홈에서는 핫딜 하위 필터와 다른 서비스가 같은 메뉴에 섞임.
- 커뮤니티 목록/글 상세, 상담, 사주 화면마다 이동 메뉴가 다름.
- 사주가 유료 상세 보고서를 판매하는데 홈에는 무료 사주로만 표시됨.
- 글 읽기/상담/사주 풀이 후 다른 서비스로 이어지는 경로가 약함.

## 반영
- 데스크톱 및 모바일 서비스 순서: 핫딜 → 커뮤니티 → 휴대폰 상담 → 이지사주.
- 홈 검색 아래 서비스 설명 카드 3개. 사주는 핵심 무료/상세 유료 구분.
- 목록/상품 상세/커뮤니티 상세/상담/광고 문의/사주에 공통 메뉴. 현재 위치 aria-current 제공.
- 커뮤니티 글 로고는 기존 요청대로 커뮤니티 목록으로 이동.
- 커뮤니티 → 핫딜·상담, 상담 하단 → 디지털 핫딜·커뮤니티, 사주 전체 보고서 끝 → 핫딜·커뮤니티.
- 무료 사주 구매 제안 영역에는 교차 홍보를 추가하지 않음.
- 홈 검색 버튼과 기존 상품/상담 링크의 희망 기종 전달 유지. 광고문의는 사업자용 하단 링크 유지.
- 공통 스타일 public/service-navigation.css, 각 HTML과 서버 렌더링 템플릿에 정적 링크. JS 실패 시에도 이동 가능.

## 검증
- 커뮤니티/SEO 기존 테스트 23개 통과.
- 격리된 로컬 화면: 390px 홈 → 커뮤니티 → 상담 → 사주 → 홈 클릭 이동.
- 320px 홈/사주, 390px 상담에서 가로 넘침 없음. 1280px 데스크톱 메뉴/카드 확인.
- 커뮤니티 상세 기존 댓글 입력 및 로고 목적지 유지 확인.
- 5개 정적 페이지의 상단/모바일 메뉴 목적지 일치 확인.
