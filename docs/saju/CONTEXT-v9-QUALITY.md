# 풀이 품질 v9 — 2026-09-29

## 확인한 문제와 변경

- v8에서는 표현→돈, 동료→돈 두 조건이 함께 있어도 첫 분기만 출력했다. v9는 두 조건이 함께 있을 때 판매액과 함께한 사람의 몫/비용 사이의 차이를 설명한다. 없는 조합에 문장을 추가하지 않는다.
- 애정운의 일지 중심 설명에 월령 중심과 다른 성향이 있는 경우 생활 장면을 더한다. 관계가 없는 경우의 계산 설명 문단은 제거했다. 이 연결은 편집적 비유이며 실제 성격을 관찰한 사실이 아니다.
- 시주 미상으로 보조 상태가 uncertain인 경우, 뿌리가 없다는 분기를 타고 버티는 힘을 단정하던 부분을 보류 문구로 대체했다.
- 계산 엔진/출생 입력은 변경하지 않았다. 기존 v8 생성기는 report-v8.js로 보존하며 저장 보고서/주문은 수정하지 않는다. 신규 기본값만 ko-context-story-9로 전환한다.

## 조사 근거와 해석의 경계

[자평진전 6장](https://donglishuzhai.net/chapter/3719.html)은 계절 한 가지로 판단하지 않고 다른 기둥과 뿌리를 함께 다룬다. [9장](https://donglishuzhai.net/chapter/3722.html)은 같은 중심도 다른 조건의 조합에 따라 달리 해석한다. 이를 조건을 생략하지 않는 설계 원칙으로 참고했다. 현대 연애/가격 협상 장면은 고전의 직접 인용이나 검증된 심리 법칙이 아닌 자체 집필이다. 형식만 바꿔 전문가 감수나 예측 정확도가 높아졌다고 주장하지 않는다.
