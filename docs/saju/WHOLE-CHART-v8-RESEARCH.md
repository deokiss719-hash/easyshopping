# 원국 관계 종합 풀이 v8: 조사·설계·검증

조사/구현일: 2026-09-29. 목표는 단일 십성별 문구를 넘어 원국의 여러 조건을 함께 읽는 것이다. **전문가 인증이나 적중률 검증을 뜻하지 않는다.** 고전은 전통 해석 규칙의 1차 자료이지 과학적 성격·미래 예측의 검증 자료가 아니다.

## 1. 초보자를 위한 조사 결론

하나의 글자가 같아도 주변 글자가 다르면 풀이가 달라져야 한다. 태어난 달만 보고 강하다고 정하거나, 돈을 뜻하는 글자만 보고 부자라고 정하는 식은 채택하지 않는다. 달의 바탕, 드러난 글자, 이를 받치는 글자, 서로 이어지거나 부딪히는 관계를 먼저 계산하고 생활 문장을 고른다. 내용은 쉬운 할머니 이야기로 유지하고 근거는 저장 데이터로 남긴다.

## 3. 계산 사실과 편집 판단의 경계

### 사실로 재현할 수 있는 부분

- 확정된 네 기둥만 사용한다. 미상 시주를 끼워 넣지 않는다.
- 월지 지장간, 각 지장간과 동일한 천간이 드러난 위치, 일간과 동오행인 지장간의 위치, 십성의 생극/음양 분류.
- 천간합·육합·육충 쌍과 위치. 완전한 삼합 세 글자 존재. 관계가 있다는 사실과 실제 작용의 크기는 다르다.
- 대운/세운의 천간뿐 아니라 지지 본기와 원국의 연결·충돌·동일 글자 반복.
- 대운 방향은 기존 두 가정 유지. 둘 다 실제 운이라거나 고객이 마음에 드는 방향을 고르는 안내 금지.

### 버전이 붙은 편집 규칙

1. 월령 중심 후보: 본기가 드러났으면 본기, 그렇지 않으면 드러난 다른 장간 중 라이브러리 저장 순서상 첫 후보, 아무것도 드러나지 않았으면 본기. 모든 후보도 기록한다. 이 우선순위는 **프로젝트의 제한된 결정 규칙**이며 유일한 정통 격국 판정이 아니다.
2. 보조 상태: 월 본기 관계, 본기/기타 뿌리 존재, 겉의 생조/소모 존재를 별도로 계산한다. 받침이 여러 조건에서 확인되면 `supported`, 받침 없이 소모만 확인되면 `limited`, 섞이면 `mixed`, 달 미확정이면 `unknown`. 신강약 점수·확정 라벨이 아니다.
3. 시주 미확정이고 월주가 확정돼 있으면 입력의 가능한 시주마다 중심/보조 상태/공존 조합이 달라질 수 있는지 민감도 검사. 보조 상태가 달라질 수 있으면 `uncertain`으로 낮춘다. 후보 시주는 실제 사실·본문 근거에 넣지 않는다.
4. 동일 조합이라도 보조 상태에 따라 금전/업무 문단을 달리 적용한다. 재성이 없다는 사실을 가난으로, 충을 이혼/사고로, 합을 결혼으로 번역하지 않는다.
5. 생활 비유 문장은 별도 편집물이다. 고전이 현대 직업·대화 행동을 직접 검증한 것처럼 쓰지 않는다.
6. 어린 나이에 사업·소득을 권하는 문장을 쓰지 않는다. 같은 시기 문장은 한 번만 쓰고 해당 나이/연도를 모아 표시한다. 구간 자체의 수치는 기존 계산 그대로다.

`report.analysis`는 파생된 구조와 한계, `report.traces[blockId]`는 문단별 규칙 ID·입력 경로·출처 ID, `report.evidence`는 실제 값이다. 구조의 존재를 기록하는 원문과 현대 생활 비유가 다름을 trace kind에도 표시한다. 근거 UI는 사용자 요청대로 숨긴 상태다.

## 4. 검증

- 관련 테스트 40개 통과(검증 시점). 기존 버전 재현, 무료 접근 제어/주문 차단, 데이터 보존, 시각 미상, 절기 경계, 음력 윤달, 표준시/서머타임 검사 포함.
- 추가 8개 테스트: 월지 장간/투출 우선순위, 통근/육합/육충/천간합/완전삼합과 반합 제외, 미상 시주의 민감도, 월주 미확정 보류, 운의 지지 변화, 같은 기존 선택값의 서로 다른 시주, 문단별 경로 추적, KASI 독립 fixture.
- KASI 공개 2026 표의 12개 월 경계와 라이브러리 시각 차이 <60초. 표가 분 단위이므로 초 단위 일치 검증이 아니다.
- 음력 12개 초하루→양력·일진 12개 일치. 검사용 미래 `now`를 주입해 계산만 검사하며 실제 고객 나이 제한은 유지.
- 12개 가상 입력: 성격/돈/일/관계의 서로 다른 본문 수 v7 8/7/8/6 → v8 11/8/10/6. 관계 문단 다양성은 이 표본에서 늘지 않았다. 단어·문장 차이는 정확도 지표가 아니다.
- 12개에서 고객 본문 전문 용어/질문 과제/미해결 근거/장 사이 동일 문장/시기별 동일 문단 자동탐지 0. 모든 의미 중복·독해 난이도를 증명하는 검사는 아니다.
- 예시 원문과 비교: [WHOLE-CHART-v8-COMPARISON.md](WHOLE-CHART-v8-COMPARISON.md). 재생성: `node scripts/saju-whole-chart-audit.js`.

## 5. 운영과 남은 한계

새 기본 버전만 일회 마이그레이션하며 기존 암호화 보고서·테스트 주문을 덮어쓰지 않는다. 이름·전화번호·회원가입 요구를 늘리지 않는다. 전체 무료·스크롤·쉬운 할머니 말투·타이핑·근거 UI 숨김 유지.

이 작업은 **원국 관계를 더 많이 고려하는 결정 규칙 엔진**이다. 인간 전문가의 실제 사례 감수, 예측 적중률, 학파 사이 일치율을 검증한 것은 아니다. 강약·격국·용신·합화 최종 판정 및 형파해·신살·정밀 조후, 경도/진태양시, 단일 대운 방향은 남아 있다. 이 한계를 숨긴 '전문가급/정확도 보장' 홍보는 하지 않는다. 과거 결과와 문구가 달라질 수 있는 이유는 데이터 변경이 아니라 해석 버전 변경이다.
