## 무료/유료
- 무료: 성격·장단점 전체, 돈·일·관계 첫 문단, 계산 기준 연도의 핵심 주제 한 문단. 계산 한계는 무료.
- 유료 샘플: 실제 금전운 마지막 문단을 명시적으로 공개. 목차4항목에 돈/일/관계/흐름 설명. 거짓 장수 표시 제거.
- 유료: 6,900원 초기값(기존 관리자 price 설정), 상세 보고서 전체. 서버 승인 전 sections/analysis/traces를 전송하지 않음.
- 기존 무료 베타 결과는 열람권 유지. 과거 무주문 보고서를 일회 보존 마이그레이션, 새 beta 발급은 별도 플래그. 주문이 있던 과거 보고서는 임의로 무료화하지 않음. 기존 암호화 payload/주문 삭제·수정 없음.
- 무료공개 범위 기존 설정3/4는 기본맛보기/금전문단추가로 표시. beta가 기본 운영 모드라 코드만으로 유료 전환되지 않음.

## 결제 선택과 실제 연동 한계
- 카카오페이 / 토스페이·토스 앱 선택. 토스뱅크 직접 계좌송금/입금확인은 구현하지 않음. 사용자 확인 질문 대기 중, 기본은 간편결제 해석.
- 기존 토스페이먼츠 v2 payment API를 유지. CARD + card.flowMode DIRECT + card.easyPay KAKAOPAY/TOSSPAY, 모바일 redirect(self).
- https://docs.tosspayments.com/sdk/v2/js/payment
- https://docs.tosspayments.com/guides/v2/get-started/environment
- 공식 환경 문서: 카카오페이는 계약 이후 MID 상점용 테스트 키 필요. 개별연동 test_ck_/test_sk_ 키 사용. test_gck 위젯 키는 이 경로와 다름.
- 실결제 또는 PG 테스트 승인은 실행하지 않음. 실행환경에 상점용 키 없음. SDK 인수 구성은 단위검사, 서버 결제 실패/중복/금액변조/불확실 승인/환불은 모의 provider/API검사.
- 향후 필요한 항목: 토스페이먼츠에서 사주 디지털 콘텐츠 업종 입점 가능 여부/간편결제 계약 확인, 상점용 테스트 클라이언트·시크릿 키, 두 간편결제 활성화. 키는 채팅/저장소에 넣지 않고 환경으로 전달. 라이브 계약/키/판매자정보와 배포는 별도 작업.

## 로컬 실행

`node scripts/saju-preview.js` → http://localhost:3417/saju

임시 PGlite 메모리 DB, 프로세스 종료 시 테스트 데이터 소멸. DATABASE_URL을 읽지 않음. 127.0.0.1에만 bind. 기본 paid + demo, 상속된 운영모드/운영키 사용하지 않음.

PG 테스트 전용: 필요한 두 test 키를 환경으로 주입하고 `SAJU_PREVIEW_PG_TEST=1 node scripts/saju-preview.js`. 테스트 접두사만 허용하고 live 키 거절. 기본 로컬 모의 모드에서는 PG SDK/API를 호출하지 않음. 실제 PG 브라우저 연결/앱전환/CSP호환은 키 연결 후 별도 검증 필요.
